BOUNDARIES AND LIMITS
A process still owns 12 base frames; heap adds 0..8 independently allocated
RW/NX frames at 0x40010000. Growth charges User before allocation, rolls back
both charge and reserved pages on failure, and never publishes a partial heap.
Shrink unmaps/invalidates before wipe/free. All variable-size frames are wiped
and returned to the immutable charge owner after exit, fault or kill.
User's 24-frame quota is unchanged: two base processes leave no heap budget;
a parent must free all heap pages to fit a base child beside itself.
No kernel heap, external crates, fork, SIMD/FPU/TLS or POSIX compatibility.

TaneFS v2 retains fixed 32-file/4096-byte layout and adds checksum sector LBA5
plus redo journal LBA264..274. Ordered flushes separate clear, payload, commit,
home update and clear completion. Acknowledged mutations crossed all barriers.
Durability assumes the device honors flush and a commit sector is atomic or
its tear is detected. Corrupt/torn commit or clear markers fail mount closed;
arbitrary power loss is not guaranteed to leave a mountable filesystem.
A disk error after commit may have taken effect despite an error return;
storage is invalidated and remount performs valid journal recovery.
FNV checksums detect accidental corruption, not adversarial forgery.

Legacy v1 is never silently reformatted. Explicit Admin file upgrade verifies
all file contents and original table, stages auxiliary checksums/journal with
flushes, then publishes the v2 superblock last. Home data/table/labels/generation
remain unchanged. Torn final superblock may refuse mounting while preserving
home bytes. Formatting is explicitly destructive and has a separate cut test.
Parent-child authority applies to user syscalls. The trusted ring0 Shell still
uses Admin/User domain MAC; User files are shared across that domain, not PID-
private. Four immutable PID-bound file handles remain checked on every use.
One child slot per live parent includes running and completed-unconsumed child;
orphan children continue without inheriting new authority. Recent shell output
remains bounded to 1024 bytes per process and eight outcomes, independent of
parent's pinned wait result. No pipes, stdin, IPC or general signal handlers.
Physical hardware/UEFI, actual disk power cuts and arbitrary stack corruption
were not tested. Network remains static ARP/NDP/ICMP without TCP/UDP/DNS.
