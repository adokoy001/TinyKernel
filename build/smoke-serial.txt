tane> about
Tane OS 0.8 - an original Rust kernel with isolated user processes.
No Linux code, GRUB, external crates, libc, or host OS calls.
Firmware loads our 512-byte boot sector; it loads this kernel.
Ring 0, own GDT/TSS/IDT, PIT at 100 Hz, E820 RAM in 4 KiB frames.
Preemptive round-robin kernel tasks with stacks from the frame allocator.
W^X paging, NX data, table-driven MAC, per-domain quotas, audit log.
ATA disk with TaneFS: labelled, checksummed files that survive reboots.
RTL8139, ARP/IPv4/ICMP, NDP/IPv6/ICMPv6; static network configuration.
Tane Shell: bounded editor, typed records, pipelines, preview and explicit apply.
Kernel tasks use ring 0; user processes use ring 3 and separate address spaces.
User faults terminate only the process. Bounded int 0x80 syscalls enforce MAC.
FPU/SIMD user instructions are unsupported and trap as #NM.
