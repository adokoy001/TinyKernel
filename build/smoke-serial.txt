tane> help
help          Show commands
about         Describe this kernel
mem           Show the memory layout, E820 map and frames
alloc         Take one zeroed 4 KiB physical frame
free ADDR     Return a frame (example: free 0x100000)
ps            List tasks
spawn KIND    Start a task: spin (CPU), beat (sleeps), once (exits)
kill PID      Stop a task and free its stack frames
uptime        Time since boot, counted by timer interrupts
echo TEXT     Print text
calc A OP B   Integer + - * / (example: calc 12 * 3)
sleep MS      Block the shell for MS milliseconds (0-60000)
fault KIND    Raise a CPU exception: bp de ud gp pf df null ro nx
sec           Show memory protection and the MAC policy
audit         Show MAC denials (admin only)
drop          Lower this shell to the user domain until reboot
clear         Clear the screen
reboot        Restart the virtual machine
halt          Stop the CPU (close QEMU to exit)
tane> about
Tane OS 0.4 - a small original Rust kernel.
No Linux code, GRUB, external crates, libc, or host OS calls.
Firmware loads our 512-byte boot sector; it loads this kernel.
Ring 0, own GDT/TSS/IDT, PIT at 100 Hz, E820 RAM in 4 KiB frames.
Preemptive round-robin kernel tasks with stacks from the frame allocator.
W^X paging, NX data, mandatory access control with an audit log.
CPU exceptions print registers; no process isolation, filesystem, or network.
